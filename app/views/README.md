# Cups & Berries — Split Static HTML

Each page uses the shared `css/style.css`.

## Storefront
- `home.html` — Home / landing page
- `menu.html` — Menu / product listing
- `product.html` — Product details
- `cart.html` — Shopping cart
- `checkout.html` — Pickup details / checkout
- `order-success.html` — Order confirmation
- `tracking.html` — Order tracking
- `account.html` — Customer account
- `login.html` — Customer login

## Admin
- `admin.html` — Admin dashboard + product/category/inventory/order/customer/promotion/report sections
- `admin-modals.html` — Add product, stock, order, customer, promotion, category, and delete screens

## Styling
- `css/style.css` — Shared stylesheet for all pages

Open `home.html` first. No server or framework is required for the static version.
